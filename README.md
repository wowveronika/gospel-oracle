# gospel-oracle

Питон-оракул: находит семь смертных грехов на веб-странице или в тексте и отвечает стихом из Евангелия.

## Как пользоваться

Проверить сайт (в терминале):

```bash
gospel https://lenta.ru
```

```

Лень         ███ 1
✝ «Всякий, гневающийся на брата своего напрасно, подлежит суду» (Мф 5:22)
```

Получить стих по настроению (в питоне):

```python
from gospel_oracle import Gospel

print(Gospel("лень"))                # стих про лень
print(Gospel("хочу бургер и торт"))  # грех угадывается по словам
print(Gospel())                      # случайный стих
```

## Что лежит в папке

| Файл | Что это |
|---|---|
| `gospel_oracle/gospel.py` | вся программа |
| `gospel_oracle/check.py` | проверка, что стихи совпадают с Евангелием |
| `gospel_oracle/data/words.csv` | слова для каждого греха |
| `gospel_oracle/data/verses.csv` | стихи для каждого греха |
| `gospel_oracle/data/gospels.json` | четыре Евангелия, эталон для проверки |
| `pyproject.toml` | паспорт библиотеки для pip и PyPI |

## Как работает программа (`gospel.py`, 4 части)

1. **Загрузка датасета.** Две таблицы превращаются в словари:
   `WORDS = {"Алчность": ["купи", "скидк", ...]}` и `VERSES = {"Алчность": ["«...» (Мф 6:24)", ...]}`.
2. **Поиск грехов.** Текст режется на слова. Если слово начинается с одного из начал в `WORDS`,
   греху добавляется +1. «Скидки» начинается с «скидк», значит это алчность.
3. **Класс `Gospel`.** У него есть магический метод `__repr__`. Питон вызывает его сам,
   когда объект печатают через `print`, и вместо служебной строки печатается стих.
4. **Проверка сайта.** Библиотека `requests` скачивает страницу, `BeautifulSoup` достаёт из неё
   текст, дальше работает часть 2, и печатается отчёт со стихом под главный грех.

## Как отбирались стихи

Правдивость проверяет программа: `python -m gospel_oracle.check` сверяет каждый стих
с Синодальным переводом слово в слово.

Подходящность проверялась вручную, по правилам:

1. Только из четырёх Евангелий.
2. Стих прямо говорит о грехе или о противоположной добродетели.
3. Понятен без окружающего текста.
4. Без угроз и проклятий: тон проекта добрый.
5. Если стих обрезан, то по границе фразы и без изменения смысла.

Списка «семи смертных грехов» в самом Евангелии нет: он сложился позже в церковной традиции.
Поэтому стихи подобраны по теме каждого греха.

Текст Евангелий: Синодальный перевод (общественное достояние), источник — github.com/thiagobodruk/bible.
